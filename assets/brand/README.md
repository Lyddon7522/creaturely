# Creaturely brand assets

The SVG files in `logos/` are the editable source assets. Use them directly on
the web or export them to PNG at the final required size.

| Asset | Intended use |
| --- | --- |
| `creaturely-logo-horizontal-primary.svg` | Default logo on white or soft-mint backgrounds |
| `creaturely-logo-horizontal-reversed.svg` | Dark teal or very dark backgrounds |
| `creaturely-logo-stacked-primary.svg` | Square placements, covers, and social graphics |
| `creaturely-mark-primary.svg` | Compact UI, favicon source, and avatar |
| `creaturely-mark-reversed.svg` | Compact mark on dark teal |
| `creaturely-logo-mono-dark.svg` | One-color printing and accessibility fallbacks |
| `creaturely-app-icon.svg` | Master source for platform launcher icons |
| `brand-board.svg` | Visual quick reference |
| `design-tokens.json` | Platform-neutral token source |
| `design-tokens.css` | Ready-to-use web variables |

Ready-to-place PNGs are in `exports/`, including a 1600 × 1100 brand board,
2× horizontal and stacked logos, a 512 px mark, and the 1024 px launcher icon.
The SVG wordmarks keep the type editable; use the PNG exports for pixel-exact
placement or convert the wordmark text to outlines before handing off to print.

The complete rules, contrast notes, messaging, and export guidance live in
[`docs/brand-guidelines.md`](../../docs/brand-guidelines.md).
